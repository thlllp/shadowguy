## Findings

### [P2] Corp-only runs can no longer sabotage or gather intel (regression)
- Seed: 950005, day 7, 1 operative, 2 AP, rival-held `wellspring`
- `010a48f` removed `intel_`/`sabotage_` rows from the Corp tab's flat action list,
  on the stated grounds that "the map's per-territory panel still offers them". It does
  not: `CorpMapScreen._TERRITORY_ACTION_PREFIXES` lists only
  `expand, secure, surveil, develop, survey, deploy, attack, newacademy, rebuild`, so
  `_refresh_map_corp_actions` filters sabotage/intel rows out.
- Steps: train an operative, return to map mode, move the cursor onto a rival-held
  district.
- Expected: a sabotage row (and intel row) for that district, as `operations_rows`
  builds them.
- Actual: the panel shows `no_territory_actions`; the Corp tab has no `sabotage_`/
  `intel_` rows either. A corp-only run (no `CorpScreen`) cannot sabotage at all.
  A hybrid runner+corp run can still do it through `CorpScreen`'s Operations panel.
- Evidence: `map actions ['no_territory_actions']`; Corp tab `sabotage rows []` with
  `operatives 1 ap 2`.
- Repro: yes, 1/1 (the filter is unconditional).

### [P2] GUI burglary-start fix does not work in the real job flow
- Seeds: 940001, 940004, 960004 (3/3)
- `529180b` added `EntranceView` push to `SceneView._show_stage`, and the regression test
  constructs `SceneView(window, scene, ...)` directly and finds `EntranceView` on top.
  But the real path is `JobsView.pick`:
  `self.window.push(SceneView(self.window, scene, ...))` — the `SceneView` constructor
  pushes `EntranceView` first, then `JobsView` pushes the `SceneView` **on top of it**.
  The picker is buried; the visible `SceneView` has zero rows.
- Steps: accept a "Burglary: …" job whose start stage is a `BurglaryStage`; stand on
  site; open `JobsView`; select it.
- Expected: the entrance picker, as the fix intends.
- Actual: `SceneView` with no rows, no prompt, only Escape (which pops the scene and
  leaves the job unplayed).
- Evidence: real-flow probe prints `stage stage_0 burglary=True … rows 0`; three seeds.
- Why the test misses it: it does not push the view after construction, so the
  entrance ends up top; the production order is the opposite.
